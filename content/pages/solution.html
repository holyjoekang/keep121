Guide v3 방향: 사람 확인과 기기 위치를 분리합니다.

Keep121 Guide는 직접 점호·QR/NFC 확인을 출발 판단의 기준으로 유지하고, 기기 위치는 미확인자 탐색을 돕는 참고 정보로 표시합니다. 태그가 버스에 있어도 사람이 탑승했다고 판단하지 않습니다.

Keep Check · 현장 확인

행사별 명단, 승하차 점호, 미확인자 담당자 지정, 인계 승인, 출발 보류, 종료 보고서. 직접 확인과 전화·소재 확인은 별도 상태로 기록합니다.

Keep Locate · 위치 출처

삼성 스마트태그3: 공식 외부 위치 API 및 계약 권한 확인 전에는 삼성 앱 병행·수동 참고 기록만 지원. 스마트폰: 동의 기반 Traccar 연동 검증. 독립형 GPS: 공급사 공식 API 확보 후 소량 시험. BLE: 근거리 기기 감지 용도로만 검토합니다.

위치에는 출처, 원본 관측 시각, 서버 수신 시각, 미수신 상태를 구분합니다. 위치가 오래되거나 원본 시각이 없으면 현재 위치로 표시하지 않습니다. 위치 기반 자동 점호 및 실시간 추적 성능은 검증·제공하지 않습니다.
