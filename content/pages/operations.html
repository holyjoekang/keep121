여행 패키지, 교육기관, 지역단체의 단체 이동을 연결합니다. 장치가 감지한 정보와 인솔자가 확인한 사실을 구분합니다.

Guide 앱 시작하기

하드웨어 3종

Keep Check · NFC·QR: 탭·스캔·직접 확인을 위한 배터리 없는 기본 명찰.

Keep Near · 단순 BLE: 주변 신호로 점호를 보조합니다. 정확한 위치·승하차를 확정하지 않습니다.

Keep Locate · GPS: GNSS와 이동통신으로 최근 위치를 전송합니다. 통신·배터리·위치 정확도와 수신 시각을 함께 확인해야 합니다.

BLE·GPS에도 NFC 또는 QR을 붙여 통신 장애 시 직접 확인합니다. 스마트폰 수신부터 시작하고 반복 통학은 차량 수신기를 검토합니다.

사용 환경별 운영

① 여행 패키지 · 3~5일: BLE 중심에 필요 인원 GPS를 혼합합니다. 집결 점호, 자유시간 대응, 매일 배터리 점검, 최종 회수를 운영합니다.

② 교육기관 · 1일 현장학습: 학급·조별 출발, 탑승, 이동, 귀교와 인계를 확인합니다.

② 유치원 등하교: 반복 노선의 승차·하차·보호자 인계와 차량 내부 최종 점검을 별도 단계로 운영합니다.

③ 지역단체 · 1일 이동: 교회·복지회·어르신 관광을 위한 간편 명단, 행사 대여, 귀가 확인과 회수입니다.

④ 인바운드 해외 여행객 · 향후: 다국어 동의·집결 안내, 여행사·랜드사 협업, 체류 기간별 장비 회수를 지원할 계획입니다.

전체 서비스 구성

Guide: 인솔자의 명단·점호·대응·회수·종료 기록.

기관 콘솔 · 개발 예정: 행사·노선, 담당자 권한, 장비 재고, 운영 보고서.

참가자·보호자 웹 · 개발 예정: 일정·동의·집결 안내와 확인된 사실의 알림.

단말 연동 · 실증 필요: BLE 수신기와 GPS API를 연결하고, 위치 시각·정확도·배터리·통신 상태를 표준화합니다.

현장 확인 원칙

인원 확인, 장치 관측, 대응 진행을 별도 상태로 기록합니다. BLE 미수신을 이탈로, GPS 수신을 탑승 완료로 처리하지 않습니다.

새 집결에서는 다시 점호합니다. 중복 확인은 인원을 늘리지 않고 취소 사유와 담당자 기록을 남깁니다.

미확인자나 미해결 대응이 있으면 출발 완료를 막습니다. 담당자가 현장과 인원을 최종 확인합니다.

장비는 등록 → 연결 → 사용 → 회수 → 연결 해제 → 충전·정비 순서로 운영합니다.

현재 앱과 개발 단계

현재 제공: 환경 선택, 명단·하드웨어 배정, 집결별 직접 확인, 지원 브라우저의 Web NFC, 태그 ID 입력, 대응 기록, 출발·종료 조건 확인, 회수 기록, JSON·CSV 내보내기.

현재 저장: 이 브라우저의 로컬 저장소. 기존 v0 기록은 유지되며 새 앱으로 자동 이관되지 않습니다. 서버 동기화·장치 관측·보호자 알림은 아직 연결되지 않았습니다.

다음 단계: BLE 실제 단말·백그라운드 수신 검증 → GPS API·3~5일 배터리 실증 → 다중 인솔자 동기화와 기관 콘솔 → 반복 통학·다국어 운영 고도화.

가격: 여행은 기간별 대여, 현장학습·지역단체는 행사 대여, 반복 통학은 기관·차량 구독을 검토합니다. 단말 원가와 실증 결과로 가격을 확정합니다.
