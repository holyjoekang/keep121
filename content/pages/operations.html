01 / PRODUCT SYSTEM

명찰과 앱, 네 가지 역할로 연결합니다.

제품 페이지의 구성을 그대로 현장에 적용합니다. Keep Check는 직접 점호, Keep Tag는 위치 확인, Guide는 판단과 기록, Keep Home은 확인된 사실의 전달을 맡습니다.

기본: Guide + Keep Check위치 필요 시: Keep Tag알림 연동: Keep Home

BLE 전용 태그는 독립 제품으로 제공하지 않습니다. 호환 Keep Tag의 BLE 근접 후보 활용은 단말·앱 연동 검증 후 적용할 기능이며, 인솔자의 확인을 대신하지 않습니다.

02 / SCENARIOS

누가, 얼마나 오래 이동하나요?

01 · 3~5일

여행 패키지

반복 집결부터 자유시간 대응까지.

Keep Check 기본 + Keep Tag 선택
운영 순서와 확인 사항

배부 → 집결마다 점호 → 배터리 점검 → 최종 회수

여행사·인솔자가 단체를 운영합니다. 참가자의 스마트폰 보유를 기본 전제로 삼지 않습니다.

02 · 일회성 / 반복

교육기관

현장학습과 매일의 등하교를 구분합니다.

Keep Check + Guide · 인계 확인
운영 순서와 확인 사항

현장학습: 출발 → 탑승 → 귀교 · 통학: 승차 → 하차 → 인계

통학 종료 시 차량 내부 직접 점검이 필요합니다. 차량 근처의 BLE 신호만으로 승하차를 확정하지 않습니다.

03 · 1일

지역단체

교회 나들이, 복지회 어르신 관광.

Keep Check + Guide · Keep Tag 선택
운영 순서와 확인 사항

명단 등록 → 배부 → 집결 확인 → 귀가·회수

비정기 행사와 자원봉사 인솔에는 NFC 점호를 기본으로 합니다. 위치 확인이 필요한 경우 Keep Tag를 선택하고, 배부·충전·회수를 함께 준비합니다.

04 · 향후 확장

인바운드 해외 여행객

언어가 달라도 집결 안내는 명확하게.

Keep Tag / Check + KeepTrip 연계 계획
운영 순서와 확인 사항

동의·언어 확인 → 집결 안내 → 자유시간 대응 → 회수

다국어 동의, 여행사·랜드사 협업, 체류 기간과 출국 일정에 맞춘 회수 체계를 개발할 예정입니다.

03 / FIELD WORKFLOW

감지에서 끝나지 않고, 확인으로 이어집니다.

01준비

명단·담당자·장비를 연결하고 착용과 배터리를 점검합니다.

02점호

집결마다 새로 확인합니다. 이전 집결의 결과를 그대로 쓰지 않습니다.

03대응

미확인자를 먼저 보고 연락·현장 확인·재합류를 기록합니다.

04종료

최종 인계를 확인하고 Keep Tag를 회수합니다. 배부형 Keep Check는 회수 없이 운영할 수 있습니다.

05 / RESPONSIBLE OPERATION

기록은 명확하게, 접근은 필요한 만큼.

확인한 사실만

신호 수신을 안전 보장으로 표현하지 않습니다. 미확인자·미해결 대응이 있으면 기본 출발 완료를 막습니다.

동의와 역할

기관 도입 전 수집 목적·기간·담당자 접근 범위를 정하고 미성년자 보호자 동의 절차를 검토합니다.

기록과 회수

배부·확인·취소·대응·회수를 기록합니다. 현재 로컬 기록은 담당자가 백업하고 기기 접근을 관리해야 합니다.
