기본 확인 수단 위에 BLE 또는 GPS를 더합니다. BLE·GPS에도 NFC·QR을 함께 부착하는 구성입니다.

Keep Near

주변의 태그를 감지하는 점호 보조

수신 거리와 환경에 영향을 받습니다. 미수신을 곧바로 이탈로 판정하지 않습니다.
GNSS + 이동통신 · 충전·통신 필요

Keep Locate

떨어진 대상의 최근 위치 확인

위치의 시각과 정확도를 함께 봅니다. 실내·통신 음영에서는 현재 위치를 알 수 없습니다.

하드웨어 구성안입니다. 현재 Guide의 BLE·GPS 자동 수신은 미연결이며, 실제 단말 실증이 필요합니다.

02 / SCENARIOS

누가, 얼마나 오래 이동하나요?

01 · 3~5일

여행 패키지

반복 집결부터 자유시간 대응까지.

BLE 중심 + 필요 인원 GPS
운영 순서와 확인 사항

배부 → 집결마다 점호 → 배터리 점검 → 최종 회수

여행사·인솔자가 단체를 운영합니다. 참가자의 스마트폰 보유를 기본 전제로 삼지 않습니다.

02 · 일회성 / 반복

교육기관

현장학습과 매일의 등하교를 구분합니다.

NFC·QR / BLE + 차량 수신기 선택
운영 순서와 확인 사항

현장학습: 출발 → 탑승 → 귀교 · 통학: 승차 → 하차 → 인계

통학 종료 시 차량 내부 직접 점검이 필요합니다. 차량 근처의 BLE 신호만으로 승하차를 확정하지 않습니다.

03 · 1일

지역단체

교회 나들이, 복지회 어르신 관광.

NFC·QR 기본 + BLE 행사 대여
운영 순서와 확인 사항

명단 등록 → 배부 → 집결 확인 → 귀가·회수

비정기 행사와 자원봉사 인솔에 맞춘 간단한 준비와 일괄 대여를 계획합니다.

04 · 향후 확장

인바운드 해외 여행객

언어가 달라도 집결 안내는 명확하게.

BLE·GPS 혼합 + 다국어 참가자 웹
운영 순서와 확인 사항

동의·언어 확인 → 집결 안내 → 자유시간 대응 → 회수

다국어 동의, 여행사·랜드사 협업, 체류 기간과 출국 일정에 맞춘 회수 체계를 개발할 예정입니다.

03 / FIELD WORKFLOW

감지에서 끝나지 않고, 확인으로 이어집니다.

01준비

명단·담당자·장비를 연결하고 착용과 배터리를 점검합니다.

02점호

집결마다 새로 확인합니다. 이전 집결의 결과를 그대로 쓰지 않습니다.

03대응

미확인자를 먼저 보고 연락·현장 확인·재합류를 기록합니다.

04종료

최종 인계와 장비 회수를 확인한 뒤 기록을 내보냅니다.

05 / RESPONSIBLE OPERATION

기록은 명확하게, 접근은 필요한 만큼.

확인한 사실만

신호 수신을 안전 보장으로 표현하지 않습니다. 미확인자·미해결 대응이 있으면 기본 출발 완료를 막습니다.

동의와 역할

기관 도입 전 수집 목적·기간·담당자 접근 범위를 정하고 미성년자 보호자 동의 절차를 검토합니다.

기록과 회수

배부·확인·취소·대응·회수를 기록합니다. 현재 로컬 기록은 담당자가 백업하고 기기 접근을 관리해야 합니다.
