# 모두의 창업 2기 · 1라운드 진행 기록

Keep121(구 SafeFlock)로 지원한 **모두의 창업 2기 1라운드** 통과 이후의 진행 내용을 모으는 폴더입니다.
운영사(멘토기관)는 **씨엔티테크**이며, 사이트의 [`modoo.html`](../modoo.html) 페이지(본문 `content/pages/modoo.html`)에 공개됩니다.

- 운영사무국 메일: modoo2@cntt.co.kr
- 모두의 창업 플랫폼: https://www.modoo.or.kr/
- 단체 카카오톡방 · 구글 Q&A 시트: 참여자 전용 (입장 링크·코드는 공개 저장소에 올리지 않음, 10/20 메일 참조)

> 갱신 방법: 사이트의 진행 상태(일정 상태·멘토링·지출·AI 솔루션·로그)는 [`data/modoo.json`](../data/modoo.json)이 기준이며 `python scripts/modoo.py ...`로 고칩니다(사용법은 스크립트 첫머리). 새 메일은 `메일/`에 요약을 추가하고, 받은 파일은 `자료/`에 둡니다. 이 문서는 프로그램 규칙과 참고 내용을 정리한 것입니다.

## 5. 창업활동자금 (200만 원)

### 핵심 규칙
1. **전용카드로만 결제.** 개인 카드·계좌이체·현금은 지급되지 않음.
2. **증빙.** 1건 10만 원 미만은 면제(카드 승인내역), 10만 원 이상은 건별 증빙, PG 결제 등 사용처 미확인 건은 금액과 무관하게 건별 증빙(주문상세·결제완료 화면·실물/서비스 사진).
3. **1건 50만 원 초과는 멘토기관 사전 승인** 후 집행.
4. 보유 사업자·법인의 지출증빙 처리나 부가세 환급 금지 (환수·제재).
5. 창업활동보고서 미제출 시 사용 금액 환수 · 참여 제한.
6. 사용 기간은 충전일~11/30, 이후 잔액 소멸. 미사용·일부 사용은 평가에 불이익 없음, 부적정 집행은 감점.

## 8. 운영사 지원 프로그램 (씨엔티테크 자율)

**1라운드 고객검증 프로그램** (내용 변경 가능)
1. 전문가 매칭 · ICP(Ideal Customer Profile) 도출 — 핵심 고객 정의
2. 고객 후보 발굴 · 미팅 연결 — 전문가가 후보 4~6명 공유, 지원자가 2~3명 선택, 최소 2명과 미팅 연결
3. 고객 인터뷰 · 결과보고 — 심층 인터뷰로 구매 의향 확인, 전문가가 결과보고서 제출

→ Keep121은 중소 여행사 인솔자·본사 담당자가 ICP 후보라 파일럿 3사 섭외와 바로 연결됨.

2~3라운드 통과자 대상: 후속 투자 연계, 성과 모니터링, 언론·유튜브 홍보 지원.
