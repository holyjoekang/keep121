Devices & Modes

Two kinds of hardware,
and the itinerary picks the mode.

In the simulation, the biggest hardware constraint wasn't weight or price but battery under continuous tracking. So Shelter became a "stretch mode" of Keep Tag+ rather than a separate device, and products are built as use-case presets, not devices.

An attendance tag that sends only BLE to the hub. On hikes and corporate trips where incidents happen while the guide leads, Keep Tag alone cut risk exposure by 74–84%.

Keep Tag+ Battery

The itinerary decides the battery

BLE stays on normally; GNSS and the modem wake only when someone is separated or on a risky stretch. Most of the drain comes from always-on Shelter stretches, so turning it on only for risky stretches is the key.

    Design principles shared by every tier

    Same BLE signal format

    One Keep121 Guide app manages Keep Tag and Keep Tag+ together. Secondary hubs (rear guide, homeroom teacher) and tags are shared.

    Anti-cloning ID

    Tag IDs rotate and are encrypted so no one can secretly track the signal.

    Android hub + keep-screen-on mode

    When hub scanning weakened, false alarms doubled. There is a hub mode that holds up with the screen on.

    Number plates and team colors

    Analog number tags and team colors apply across every tier.

    Alert Design

    If every alert goes off,
    it's as if none did.

    Large teams got more than 25 alerts a day. So alerts are split into 3 levels and only Urgent makes a sound. Thresholds were set where false alarms and response speed balanced in the sensitivity analysis.

    False-alarm suppression rules

    • The same tag won't repeat the same alert until it is detected again.
    • If 3 or more people leave together in the same direction, it counts as one alert (group free time).
    • Tags the guide has "visually confirmed" have Caution alerts muted for the day. Urgent is never muted.
    • On the bus, exit alerts are off while inside the vehicle fence; at the hotel, night mode takes over.
    • GNSS reports that arrive more than 1 minute late are used only for location history, not for alert decisions. They were a main cause of false alarms in dead zones.
