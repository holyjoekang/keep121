# SafeFlock — 부모님 여행, 잘 도착하셨을까?

단체여행 안전 플랫폼 SafeFlock 소개 홈페이지 (GitHub Pages).

**https://holyjoekang.github.io/safeflock/**

## 구성

- `index.html` — 원페이지 소개 사이트 (문제 인식 · 솔루션 · 작동 방식 · 라이브 지도 데모 · 디바이스 · 가족 안심 · 여행 기록 · 안전 시나리오 · 활용 분야 · 소싱 · 비즈니스 · 로드맵 · 창업자 · 파일럿 문의)
- `assets/css/style.css`, `assets/js/main.js` — 스타일과 인터랙션 (원탭 출석 체크, Leaflet 줌인 지도, 밴드 컬러, 가격 계산기)
- `story/` — 이전 버전 상세 페이지

## 로컬 실행

```bash
python -m http.server 5173
```

모든 화면과 수치는 콘셉트 시안·목표치이며 검증된 실적이 아닙니다.
