Keep121 Guide

첫 화면은
큰 숫자 하나.

가이드가 하루 수십 번 여는 화면입니다. 누구를 찾아야 하는지만 보여주고, 판단은 가이드가 합니다. Android 네이티브(Flutter)로 백그라운드 BLE·NFC를 안정적으로 씁니다.

  • 명단 엑셀 업로드 · 투어와 명찰 번호를 한 번에
  • NFC 탭 또는 BLE 근접 후보 + 가이드 1회 확인
  • 버스 출발 후 3분 안에 미승차자 경보
  • 모든 경보에 원탭 라벨 · “확인함 / 오경보”
  • 종료 리포트 · 점호 횟수·시간, 경보와 해결 시간

이벤트 로그 스키마(누가, 언제, 어디서, 경보 등급, 라벨, 해결 시간)를 앱 기능보다 먼저 설계합니다. 이 기록이 사고 타임라인과 경보 튜닝의 원천입니다.

Keep Tag · Keep Check

손목밴드가 아니라,
목에 거는 명찰.

단체여행에서 이미 익숙한 명찰 형태라 착용 거부감이 적고, 배포와 회수가 쉽습니다. 손목형은 본인이 원할 때와 아동용 옵션으로만 둡니다.

Keep Tag — GPS·LTE 명찰

이탈 시 위치를 찾는 명찰형 트래커입니다. 자체 개발 대신 아래 조건을 모두 갖춘 KC 인증 기성품으로 시작합니다 (Plan A).

  • KC 인증 · 전파법 적합 모델만 사용
  • 국내 등록 위치정보사업자 플랫폼 연동 · 좌표는 등록사업자가 수집
  • API 제공 · 명찰형 · 해외 로밍

조건을 갖춘 모델이 없으면 Plan B: 국내는 통신사 시니어·키즈 트래커 API를 쓰고, 출결은 Keep Check로 휴대폰 안에서만 처리합니다. W2(10/23~29)에 적격 모델 3종의 실명·단가·회선 구조를 확인해 결정합니다.

Keep Check — 무단말 NFC 명찰

배터리도, 회수도 필요 없는 NFC 명찰입니다. 개당 약 100원이라 capex가 없고, 지불 저항이 큰 여행사의 진입 상품이자 서버에 위치를 저장하지 않는 중국 상품의 점호 전용 모드로 씁니다.

Hardware Strategy

수요가 증명될 때까지,
단말은 사서 씁니다.

자체 단말의 NRE·인증 비용 약 1억 원은 초기 실적으로 정당화되지 않습니다. 단계마다 전환 관문을 두고, 관문을 넘을 때만 다음 단계로 갑니다.

단계기간단말착지 단가전환 관문
① 기성품2026.11~2027Plan A/B 조건의 KC 기성 트래커6만 원W2에 적격 모델 3종 실명·단가·회선 구조 확인
② 화이트라벨2028~2030 상반기같은 계열에 로고·명찰 케이스·서버 연동5만 원Gate 1, 연 수요 300대, 개인위치정보사업 등록 신청
③ 자체 ODM2030 착수 · 2031 양산명찰형 1종, 기내 LTE 자동 차단, OTA, 서버 이전 가능4만 원연 수요 3,000대 또는 렌탈 월 200투어, 등록 완료, 오경보 투어당 0.5건 이하

선전·광저우 네트워크는 원가 해자가 아니라 빠른 커스텀과 수리·교체 회전에 씁니다. 적격 모델을 최소 2종 확보해 단일 공급처 위험을 줄이고, 2031년 이후에는 타사 트래커·스마트폰 체크인을 수용해 단말 매출 비중을 25% 이하로 낮춥니다.
